Core Features

🏢

Multi-Branch Management

Manage inventory across multiple branch locations with centralized warehouse oversight and inter-branch transfers.

🔐

Role-Based Access

Three-tier authorization system (Admin, Manager, Clerk) with JWT authentication and granular permissions.

🔄

Automated Restock

PostgreSQL triggers automatically create restock requests when inventory falls below threshold levels.

📊

Stock Movements

Track all inventory changes including sales, withdrawals, adjustments, and transfers with full audit trail.

📝

Audit Logging

Database-level triggers capture every stock change with timestamps, user attribution, and before/after values.

🤝

Supplier Management

Link suppliers to items, manage contact information, and track which suppliers provide which products.

📈

Reports & Analytics

Real-time dashboards with low-stock alerts, movement history, and aggregated statistics by branch.

🎨

Modern UI

React-powered interface with toast notifications, confirmation dialogs, loading states, and theme support.

  • trg_audit_branch_stock

  • trg_audit_warehouse_stock
  • Logs warehouse stock changes

Stored Procedure

  • sp_fulfill_restock_request
  • Atomically transfers stock from warehouse to branch, updates both inventories, and marks request as fulfilled
