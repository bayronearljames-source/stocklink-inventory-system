Core Features

🏢
Multi-Branch Management

Manage inventory across multiple warehouse locations with centralized control and branch-specific stock levels.

🔄
Automated Restock Workflow

PostgreSQL triggers automatically generate restock requests when stock falls below threshold levels.

🔐
Role-Based Access Control

Three-tier permission system (Admin, Manager, Clerk) with JWT authentication and protected routes.

📊
Real-Time Analytics

Comprehensive reports and dashboards showing stock levels, movements, and restock request status.

🔍
Complete Audit Trail

Automatic audit logging of all stock changes via database triggers for compliance and tracking.

🤝
Supplier Integration

Manage supplier relationships with item linking, contact information, and restock request routing.
